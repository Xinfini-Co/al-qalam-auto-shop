## Project Overview

A cloud-connected Flutter application (Windows desktop + browser) that connects directly to Supabase — no custom backend server required, which keeps ongoing costs low. All data is stored securely in the cloud and accessible from any authorized device. Includes user authentication, role-based access, PDF storage, and real-time data sync.

---

## Scope of Work

| # | Module | Description |
|---|---|---|
| 1 | Auth & Roles | Email/password login, Admin + Staff roles via Supabase Auth |
| 2 | Client Management | Add, edit, search clients |
| 3 | Vehicle Management | Vehicles linked to clients |
| 4 | Job / Repair Orders | Create jobs with line items, status tracking |
| 5 | Invoice Generation | Auto-generate from jobs, branded with shop logo |
| 6 | PDF Export & Storage | PDF saved to Supabase Storage, downloadable locally |
| 7 | Payment Recording | Full/partial payments, payment history |
| 8 | Outstanding Tracker | Dashboard for unpaid/partially paid invoices, overdue alerts |
| 9 | Reports | Revenue, jobs, outstanding balance, top clients — export PDF/CSV |
| 10 | Shop Settings | Logo upload, name, address, VAT, invoice numbering, user management |
| 11 | Supabase Setup | Schema design, RLS security policies, Storage buckets |
| 12 | UI | Arabic + English, light/dark mode, RTL support, responsive layout |
