## Project Overview

A fully offline Flutter desktop application for Windows that handles the complete invoicing workflow — clients, vehicles, repair jobs, invoice generation, PDF export, payments, and reports — with no internet dependency.

---

## Scope of Work

| # | Module | Description |
|---|---|---|
| 1 | Client Management | Add, edit, search clients |
| 2 | Vehicle Management | Vehicles linked to clients |
| 3 | Job / Repair Orders | Create jobs with line items, status tracking |
| 4 | Invoice Generation | Auto-generate from jobs, branded with shop logo |
| 5 | PDF Export & Print | Local PDF generation and direct print |
| 6 | Payment Recording | Full/partial payments, payment history |
| 7 | Outstanding Tracker | Dashboard for unpaid/partially paid invoices |
| 8 | Reports | Revenue, jobs, outstanding balance — export to PDF/CSV |
| 9 | Shop Settings | Logo, name, address, VAT rate, invoice numbering |
| 10 | Backup & Restore | Export/import full local database |
| 11 | Windows Installer | `.exe` installer for clean Windows 10/11 installation |
| 12 | UI | Arabic + English, light/dark mode, RTL support |
